# Physics-Informed 3D Seismic Reconstruction

## Project Overview

This project investigates a 3D encoder–decoder framework for seismic data reconstruction using synthetic seismic data and acoustic wave-equation physics constraints.

The objective is to reconstruct missing seismic information while investigating the contribution of physics-informed learning and predictive uncertainty estimation.

## Research Focus

- 3D seismic data reconstruction.
- Encoder–decoder neural network architecture.
- Acoustic wave-equation physics loss.
- Predictive uncertainty estimation.
- Evaluation of reconstruction quality.

## Experimental Scope

This repository is intended for a separate synthetic-data experiment using acoustic wave-equation physics. It is maintained independently of the original synthetic Eikonal-loss experiment and the F3 dataset project.
